# 海洋工程原理界面

工程原理页按用户选定的海洋概念图应用全幅海面与水下背景、波浪曲线侧栏、半透明说明面板与青色发光模块选择条。通过 SVG 曲线与渐变透明填充实现异形面板；导航和说明文字保持真实 HTML 交互。

选中模块同步顶部倾斜高光、说明、输出通道、载荷箭头、图中标注与底部耦合节点。保留向下阅读、原生可展开问答、官方文档与工况配置入口。支持键盘方向键及减少动态效果设置；窄屏依次展示模型、说明和耦合节点。

海景使用内置 imagegen 从已选概念图重建为干净背景，提示词见 engineering-ocean-prompt.txt。背景风机、海床和刻度为视觉示意，不是精确模型或真实求解结果。代码还原概念图构图和视觉效果，但并非将整张概念图作为不可交互页面，且不声称像素完全一致。

真实 OpenFAST 引擎、工况校验、账户和报告流程未作修改。

叶轮改为独立 SVG 金属渐变动画层，背景清除静态叶片，避免双重叶轮。桌面背景放大 12%，机组随之稍微下移；顶部模块改为右侧五列网格，避开叶轮扫掠区，完整容纳控制与发电。支持动画暂停、页面不可见暂停与减少动态效果偏好。此动画不代表仿真输出。
