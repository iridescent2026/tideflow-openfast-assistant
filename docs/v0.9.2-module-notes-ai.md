# 工程原理：图像与说明分栏

- 左侧保留模块名称和放大的结构插图，标题、简介和三条模块字段移至右栏；移除右侧旧问答列表。
- 右侧加入“问问 AI”，复用现有内存中的接口配置和本机 AI 转接。仅发送问题、当前模块说明与字段，不添加运行结果；未配置连接时明确提示配置，不生成替代回答。切换模块会隐藏旧回答，连接更改或断开会取消进行中的请求。
- 保留原“查看系统结构线图”和“开始配置工况”节点及事件。
- 为三步波浪长卷底部说明增加安全空间；系泊恢复力标注向左让开主面板。

验证：五模块切换、三条字段同步、未连接提示、AI 配置弹窗、线图展开/收起、配置页跳转，及 390px 窄屏无横向溢出。已有 Python 与 JavaScript 回归检查全部通过。未使用真实密钥调用外部模型。
