# 模型结构页：深海视觉设计落地

按用户选定的深海观测舱效果图实现界面。页面采用全屏海洋环境、左侧编号导航、彩色潮汐标志、右侧切角半透明说明面板、部件文字标签与底部四项悬浮视图工具。所有文字、按钮、参数及面板均为 HTML/CSS/JavaScript，中央为原有可交互 WebGL 三维模型。

主体文件：`dist/model-ocean.css`、`dist/model-ocean.mjs`；模型交互仍由 `model-explorer.mjs` 与 `model-renderer.mjs` 实现。样式限定在模型结构页，保留其他页面的现有设计与功能。

## 视觉边界

背景使用内置 imagegen，从用户选定效果图生成独立的无文字、无风机海洋环境图 `dist/assets/model-ocean-environment.png`。它是艺术环境，不是海域观测或按比例水深剖面。背景水面纹理、光束与海床不参与模型坐标计算；界面标为“示意景深”，未复制概念图中与实际几何不一致的数值水深刻度。

保留参考输入构建的三维几何比例，而不为匹配概念图拉伸平台或压缩风机；因此模型形状、材质与像素轮廓并非与概念图完全相同。真实模型可旋转、缩放、点击聚焦与切换视角，不以整张效果图替代可交互界面。

新增 RoomEnvironment（与现有依赖同为 Three.js r180，MIT 许可）用于本地环境反射，并加入真实三维投影。依赖本地提供，无在线 CDN。
