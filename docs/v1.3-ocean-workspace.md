# v1.3 海洋工作区

本次更新统一实验舱与 05—07 页的海洋风格，同时保留原有真实引擎、运行记录和报告证据流程。三个新页面通过 app.mjs 的只读状态桥接及原有操作入口工作，不建立第二套演示运行数据，也不重复轮询引擎。

## 05 结果分析

- 功率、平台纵摇、转子转速三图联动，支持最多四个已完成工况比较。
- 曲线用 6 秒从左到右显现，完成后停留 3 秒，再循环；可切换静态显示。系统减少动态效果偏好默认采用静态模式，页面不可见时停止动画。
- 时间导航提供两端拉轴、可拖动选区、键盘平移与数值输入。选区变化立即更新曲线范围、时间加权统计和数据表，可切换全时序视图。
- 端点在相邻真实样本间线性插值，统计按时间积分；CSV 导出选区内的原始样本。比较限制在共有时间范围内。
- 互动查看窗口与运行原本的正式分析窗口分开；报告仍使用正式分析窗口。修改风浪配置需提交新计算，不会把旧曲线变形成新仿真结果。

## 06 运行与日志

按实际状态展示准备、运行、完成、失败和取消任务。进度来自运行记录；日志保留原文，支持级别筛选、搜索和自动跟随。取消、导入、备份、下载日志及输出沿用现有操作。工况与输入清单导出为参数及哈希 JSON，不冒充原始求解输入文件。

## 07 分析报告

五段目录配合纸张阅读区和结论依据侧栏，继续使用已有报告生成器中的真实统计、曲线、参数、哈希与来源。支持 Markdown 下载、本机浏览器保存与恢复报告；PDF 按钮调用浏览器打印，由用户选择保存为 PDF。恢复的 HTML 经过标签、属性及链接协议过滤。AI 辅助撰写复用已有连接与实际上下文。

## 启动与实验舱

单一模块入口按依赖顺序初始化，避免增强模块并发执行造成旧版白色内容与海洋侧栏叠加。独立增强模块失败不会阻断后续模块。实验舱补充座椅、弧形控制台、玻璃地板与结构细节；落座界面使用参考构图素材叠加真实可操作控件，起身后恢复三维走动。
