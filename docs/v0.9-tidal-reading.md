# 潮汐图册阅读区域

按用户选定的 A 概念应用下滑阅读区域：深海环境、SVG 波浪玻璃长卷、三步原理图解、异形模块剖视面板和原生可展开问答。正文、模块说明和输出字段保留 HTML，插图与曲线明确标为原理示意，不显示伪造仿真结果。

模块面板与首屏的五模块选择联动；水动力和系泊使用平台线图，其他模块使用机舱概念剖视插图，名称和说明随模块切换。系统线图通过独立按钮展开，工况入口继续使用现有路由。当前模块的计算边界移入“图与仿真关系”问答中。

首屏控制箭头旁补充“控制与发电 / ServoDyn”可点击标注。工程原理页固定展开左侧导航，隐藏收起入口，Escape 不再收起；离开本页后其他页面保留原有导航行为。窄屏使用缩窄固定导航，并为图册正文保留左侧安全区。

背景 tidal-reading-ocean.png 复用项目已有 model-ocean-environment.png 海洋资产。机舱剖视使用内置 imagegen 生成，透明背景，提示词见 tidal-reading-assets-prompts.txt。插图为概念外观，不能用于结构尺寸测量或控制器实际安装位置判断。
