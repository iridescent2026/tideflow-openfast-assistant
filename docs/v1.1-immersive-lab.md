# 全景海洋实验舱

工况配置升级为本机 Three.js 渲染的可交互空间。玻璃穹顶、滑动双门、操作座椅、环形桌面、风机与旋转叶轮均为场景几何。晴天海洋全景纹理由内置 imagegen 生成，提示词见 lab-panorama-prompt.txt；它仅作为环境和反射材质，不包含界面控件。

## 体验流程

1. 点击“进入实验舱”，门扇打开后镜头进入舱内。
2. W/A/S/D、方向键移动，拖动画面环顾；手机使用方向按钮。行走范围限制在舱内和控制台前方。
3. 点击座椅或其文字标记，平滑落座，点亮三个参数屏。
4. 用滑杆、数值输入或下方旋钮调整风速、波高和周期；JONSWAP 显示随机种子。
5. 点击提交真实仿真，仍通过原有表单校验和本机 OpenFAST 接口提交。起身恢复行走，也可返回舱外。

“直接落座”和“参数面板”提供快捷路径。减少动态可停止海浪与叶轮预览并缩短过渡；设备的减少动态偏好也会生效。离开配置页或隐藏页面时暂停三维绘制与移动。WebGL 初始化失败时自动打开参数面板。

## 数据与边界

- 复用现有输入节点、表单事件、验证、恢复默认和运行按钮，没有增加第二套仿真参数。
- 环境动画随输入变化，仅表达配置预览；没有把演示叶轮转速或波形作为计算结果。
- 虚拟舱室是产品交互场景，不是 OC4 平台上的真实舱室工程设计。

## 验证

浏览器验证完整开门/进舱/落座/起身循环、键盘移动、三个实体控制按钮、规则波和 JONSWAP 切换、随机种子、参数指南、跨页面返回。非法分析窗口提交被拦截。390px 手机布局无横向溢出、控制台可滚动。未为验证界面而提交新的真实计算。

新增 5 个移动与镜头单元检查：朝向、斜向速度、边界、长帧限制和缓动端点。

## 入口细节

入口按选定近景重建为弧形银白外壳、固定侧窗、独立滑动玻璃门、双层金属包边、竖向把手、门禁灯、右侧品牌标识与镜面栈桥。门口的外圈结构预留缺口，进舱通道保持畅通。
