## 立即运行本机完整版本

本工作区已经下载官方引擎及模型。无需 npm 或 pip 依赖，Python 3.10+ 标准库即可启动：

```powershell
python server.py
```

打开 **http://127.0.0.1:8766** 。也可右键 `start.ps1`，选择使用 PowerShell 运行。启动前检查引擎及模型哈希。用 `stop.ps1` 停止后台工作台；当前任务会取消。命令行前台服务使用 Ctrl+C 停止。

没有配置 Python 命令时可使用本机 Codex 自带环境：

```powershell
& "$env:USERPROFILE\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe" server.py
```

**线上版与本机版：**线上网页能展示内置真实算例、导入结果、对比、解读日志及生成报告；运行新的数值仿真需要打开本机工作台。线上不会伪造启动进度，也不会用插值结果冒充 OpenFAST 新计算。

## 首版功能

- 稳定风速、规则波 / JONSWAP 不规则波、波高 / 显著波高、周期 / 峰值周期、随机种子、运行时长与分析窗口配置。
- 本机 OpenFAST 异步执行、基于原始时间日志的进度、取消运行、失败记录与输出完整性检查。
- 功率、转速、平台纵摇 / 纵荡、波面高程、塔底弯矩的完整时序图；最多四工况叠加。
- 时间加权均值、绝对峰值、RMS、标准差和窗口发电量。统计使用全部输出样本，显示图形可能抽点。
- 原始日志、带证据与文档链接的规则排查、可选的大模型讨论。
- 分析窗口前后半段复核、对照变量差异提示、两种求解步长及最长 3600 s 的人工工况配置。可配置范围不等于已验证的工程适用范围。
- 本机 AI 转接及文本连接检测；按关键词选择官方文档摘要，显示 K 编号依据。此知识库为人工整理摘要，不是完整全文检索。
- JSON 记录与工作区导入导出、OpenFAST 文本 .out 导入、CSV、可打印 HTML 分析报告。

## 建议演示流程

1. 打开基准工况：8 m/s、规则波高 1.5 m、周期 10 s、仿真 120 s、分析 60—120 s。
2. 与风速 11.5 m/s 工况比较，观察平均功率、转速与平台运动。
3. 比较“单变量 · 规则波高 3 m”或“单变量 · JONSWAP 1.5 m”；旧“海况对比”保留为同时改变两个因素的混杂示例。
4. 在本机只改变一个参数提交新工况，检查真实日志进度；可取消正在运行的任务。
5. 勾选记录叠加曲线，查看分析窗口、源文件哈希，生成报告。
6. 粘贴实际报错日志，查看规则定位与原文证据；规则未命中不表示没有问题。

## 模型与来源

- OpenFAST **v5.0.0，Windows double precision**，来自官方发布的 `OpenFAST_Double_Release.exe`。
- 官方 `DISCON_OC3Hywind.dll` 控制器。
- NREL 5 MW / OC4-DeepCwind 半潜式参考平台，水深 200 m。
- r-test 固定提交：`dd5feaaaa500ba7283140107806300d551cff0a7`，由 OpenFAST v5.0.0 的 r-test 子模块引用确定。
- 基础算例：`5MW_OC4Semi_WSt_WavesWN`。工作台将白噪声波浪设定改为所选规则波或 JONSWAP 波浪，改变稳定风速和时长，并输出文本时序。
- 结构、系泊、控制器和初始状态保持官方基准设置；风向与波向不作为首版可调参数。
- 引擎文件、输入文件、原始输出均记录 SHA-256；下载的模型文本用官方 Git blob SHA-1 核对。官方资产提供 SHA-256 时也核对。
- 模型为公开参考模型，工况为人工设置，不是实际风场或海域观测。

官方程序：https://github.com/OpenFAST/openfast/releases/tag/v5.0.0

## 首次安装或迁移到另一台 Windows 电脑

```powershell
.\install.ps1
.\start.ps1
```

安装程序从官方 GitHub 下载固定版本可执行文件、控制器和所需模型引用，不修改全局 Python 环境。运行依赖保存在 `runtime/`，此目录不上传 Sites 源码仓库。当前安装器针对 Windows x64；其他系统需要接入其原生 OpenFAST 程序。

源码包已包含完成的展示记录，新电脑不需要重算即可查看。`tools/build_samples.py` 可实际运行完整验证集，并打包真实记录；已完成且参数一致的记录会复用。原始完整输出与日志保存在 `runtime/jobs/<运行ID>/`。仅导出已有记录使用 `python tools/build_samples.py --export-only`。

只检查安装完整性：`python tools/doctor.py`。重新生成数值观察报告：`python tools/report_validation.py`（需要所有指定运行已完成）。验证集包含初始 3 组、2 组单变量对照、2 组追加种子、1 组半步长和 1 组 600 s 运行，共 9 组；实际完成情况以验证报告为准。

## 统计口径

输出步长 0.1 s，求解步长默认官方 0.0125 s，可选择 0.00625 s 做敏感性检查。完整时序从 0 s 开始保留，统计只使用用户选择的分析窗口。

- 均值：窗口内按时间梯形积分，再除以实际时间跨度。
- RMS：平方值积分的时间均值开平方。
- 标准差：`sqrt(max(0, RMS² - mean²))`，时间加权总体统计。
- 窗口发电量：功率 `kW` 对时间 `s` 积分，再除以 3600 得到 `kWh`。
- 绝对峰值：所选窗口内采样输出的最大绝对值，并非连续时间真实峰值或安全阈值。

前后端分别实现统计并交叉核对。拒绝单位不匹配、NaN、时间不递增、缺失必需通道和未覆盖完整时长的输出。取消或失败任务的部分输出不当作完成结果。

## 模型边界

120—300 s 是演示级短时仿真，不保证已达到充分稳态。排除前 60 s 也不自动证明后续窗口已经稳态。模型未进行特定工程校准、疲劳寿命分析、极限工况认证或实测验证。不得将短时窗口直接外推为全年发电，不自动给出结构安全结论。

比较时需要核对工况参数、初始条件、分析窗口和随机种子。不规则波的短时样本统计不一定等于目标海况参数。固定模型可调范围仅为本工具的实现范围，不是经过认证的适用域。

## 导入已有结果

- 运行记录 JSON：使用网页“导出记录”的格式，或工作区 JSON（包含 runs 数组）。
- OpenFAST `.out` 文本：导入前先在左侧配置相应的工况参数、仿真时长和分析起点。文件本身不能证明这些参数，导入后会标注来源待核验。
- 最多保留 50 条用户导入记录，每个文件不超过 12 MB。导入的统计会从时序重新计算，不信任外部 JSON 中声明的统计值。
- 暂不支持二进制 `.outb`、任意自定义模型上传或任意命令执行。

## 大模型接入

在网页填写支持 Chat Completions 格式的完整 URL、模型名和密钥。本机版通过同源 `/api/ai` 转接，无需服务允许浏览器 CORS；静态版直接调用，需要 CORS。只允许 HTTPS 或本机 HTTP，不跟随重定向。密钥在页面及单次本机请求内存中使用，刷新清除，不写磁盘、工作区、报告或运行记录。

“检测连接”仅发送测试提示词，不发送仿真数据，验证是否返回文本。实际提问发送选中运行的参数、统计、日志节选、窗口检查及相关文档摘要；引用编号对应页面显示材料。当前没有真实 API 账号，自动测试使用明确标注的本地假服务，只验证协议与错误处理，不能视为真实模型质量评测。

未接入时明确使用规则解释，日志规则匹配同时展示证据与官方文档。大模型故障时会显示错误并恢复规则解释，不伪装成模型回答。数值始终来自 OpenFAST 或导入的时序数据。

## 本机接口与隔离

本机服务仅监听 127.0.0.1。新建 / 取消任务需要同源请求和页面获得的临时运行 token；拒绝外站 Origin 和非本机 Host。该 token 不写磁盘。接口只调用固定可信程序和固定模型，用户输入限于白名单数值字段，使用 subprocess 参数数组且不经过 shell。

每个工况复制到独立目录，保留输入快照。超时为 `max(600, 仿真时长 × 8 + 120)` 秒；长时运行可以主动取消。操作系统文件锁避免不同工作台或批量脚本同时提交仿真；进程退出自动释放。故障注入工具在另外的模型副本运行，不修改可信参考模型。

## 检查

```powershell
python -m unittest discover -s tests -p "test_*.py"
node --test tests/core.test.mjs
```

测试包含参数及输入修改、单位与积分、异常时序拒绝、真实故障日志、进程锁、AI 请求与错误处理、真实样例完整性以及 Python / JavaScript 统计一致性。AI 协议测试使用本地假服务，人工数值夹具仅用于测试，不混入展示算例。
